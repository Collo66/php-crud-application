# PHP CRUD Application

## Project Description

This project is a PHP and MySQL-based CRUD (Create, Read, Update, Delete) application developed to manage user records.

It allows users to add, view, edit, and delete user information.

## Technologies Used

* PHP
* MySQL
* HTML
* XAMPP
* phpMyAdmin

## Features

* Add new users
* View user details
* Update user information
* Delete user records
* Store user information in a MySQL database

## Database

* Database name: `phpcrud`
* Table name: `tblusers`

## Installation and Usage

1. Install XAMPP.
2. Copy the `phpcrud` folder into `C:\xampp\htdocs`.
3. Start Apache and MySQL using XAMPP.
4. Open phpMyAdmin and create the `phpcrud` database.
5. Import the database SQL file if provided.
6. Open your browser and visit `http://localhost/phpcrud/`.

## Project Files

* `index.php` – Displays user records.
* `insert.php` – Adds new users.
* `read.php` – Displays individual user details.
* `edit.php` – Updates user records.
* `dbconnection.php` – Connects PHP to MySQL.
* `Dockerfile` – Docker configuration.
